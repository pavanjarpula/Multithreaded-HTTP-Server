C++ Multithreaded HTTP Server

A production-quality HTTP/1.1 server built from scratch using low-level TCP sockets.

Features

  • TCP socket programming with Winsock2/POSIX
  • Fixed-size thread pool with task queue
  • HTTP/1.1 request parsing
  • Static file serving with MIME types
  • Thread-safe logging and metrics
  • Graceful shutdown on SIGINT/SIGTERM

Try It

curl http://localhost:8080/health
curl http://localhost:8080/hello
curl http://localhost:8080/metrics
curl -X POST -d "test body" http://localhost:8080/echo
