Core Technologies

C++17

Modern C++ with std::thread, std::atomic, std::optional, std::filesystem

TCP Sockets

Raw socket() / bind() / listen() / accept() / recv() / send()

HTTP/1.1

Request parsing, header extraction, Content-Length body handling

Thread Pool

Fixed-size worker threads with bounded blocking task queue

Backpressure

Bounded queue with HTTP 503 Service Unavailable on overload
